# API (FastAPI)

**Chủ thư mục:** D

Nạp model tốt nhất từ HF Hub theo `hf_model_repo` + `hf_model_revision` trong `configs/paths.yaml`; tiền xử lý dùng `src/preprocessing/`. Cách tải model: [`docs/huggingface.md`](../../docs/huggingface.md) mục 5.

Muốn sửa thư mục này mà không phải chủ: mở PR và cần chủ thư mục đồng ý.
